# Калькулятор СС

Калькулятор систем счисления. Работает в браузере, сборка и сервер не нужны.

Сайт: https://flew96.github.io/calculator-cc/ (English: https://flew96.github.io/calculator-cc/#en)

## Что умеет

- Перевод между системами с основаниями от 2 до 36: строки для 2, 8, 10, 16 и своего основания. Число можно вписать в любую строку.
- Целые и дробные числа любой длины. Значение хранится как точная дробь, поэтому округлений нет, а бесконечные дроби показываются с периодом в скобках: `0,1₁₀ = 0,0(0011)₂`. Период можно и вводить: `0,(3)`.
- Пульт с тумблерами в стиле старых ЭВМ: каждый тумблер это бит, группы по 3 и 4 бита показывают восьмеричные и шестнадцатеричные цифры.
- Разбор перевода вручную: общий алгоритм для любого основания и тот же алгоритм на введённом числе. Для целой части показаны деление с остатком, сумма по степеням и схема Горнера, для дробной — умножение и отрицательные степени.
- Два языка, русский и английский: переключатель в шапке, по умолчанию язык браузера, ссылка с `#en` или `#ru` открывает нужный. В английском дробь пишется через точку, а запятая разделяет тысячи.
- Необычные системы: римская, сбалансированная троичная («Сетунь»), фибоначчиева и факториальная.

## Запуск

Откройте `index.html` в браузере. Шрифты подгружаются из Google Fonts, без интернета страница откроется с системными шрифтами.

## Устройство

| Файл | Что внутри |
|------|------------|
| `index.html` | Разметка страницы |
| `style.css` | Стили, светлая и тёмная тема |
| `convert.js` | Вся математика без DOM: разбор ввода, точные дроби, перевод между основаниями, периоды, римские и другие системы. Работает и в браузере (`window.Convert`), и в Node |
| `i18n.js` | Тексты интерфейса на английском и строки, которые собирает app.js, на обоих языках. Русский текст разметки лежит прямо в `index.html` |
| `app.js` | Состояние страницы, конвертер, пульт, разбор перевода, переключение языка |
| `tests/convert.test.js` | Тесты для `convert.js` |

Скрипты подключены обычными `<script src>`, без модулей, поэтому страница работает и при открытии файла двойным щелчком.
